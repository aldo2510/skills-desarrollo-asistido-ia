# Desarrollo asistido por IA con GitHub Copilot

Laboratorio práctico para usar GitHub Copilot durante el ciclo de desarrollo: entender, planificar, implementar, probar, depurar y preparar un Pull Request.

## Objetivos

- Analizar una base de código con Copilot.
- Convertir un requerimiento en un plan.
- Implementar una funcionalidad con Copilot Agent.
- Generar y ejecutar pruebas.
- Investigar y corregir un bug.
- Preparar un Pull Request con ayuda de IA.

## Duración

50-60 minutos.

### Cómo empezar

Copia este ejercicio a tu cuenta y espera unos segundos para que GitHub prepare la primera lección.

[![](https://img.shields.io/badge/Copy%20Exercise-%E2%86%92-1f883d?style=for-the-badge&logo=github&labelColor=197935)](https://github.com/new?template_owner=aldo2510&template_name=skills-desarrollo-asistido-ia&owner=%40me&name=skills-desarrollo-asistido-ia&description=Exercise%3A%20Desarrollo%20asistido%20por%20IA&visibility=public)

### Progresión

1. Conoce el proyecto.
2. Analiza un requerimiento.
3. Implementa con Copilot Agent.
4. Genera pruebas.
5. Depura con IA.
6. Cierra el ciclo con un Pull Request.
